Audio Memory

Запоминает выбранную озвучку отдельно для пользователя и сезона.

Включая пользователей, которые будут добавлены позже. У каждого будет свой выбор озвучки.

Выберите пользователей

Если никто не выбран, запоминание отключено для всех.

Обучение происходит при ручной смене аудиодорожки во время просмотра.

При пустом названии сохраняется индекс дорожки; если порядок в следующей серии отличается, озвучка может оказаться другой.
