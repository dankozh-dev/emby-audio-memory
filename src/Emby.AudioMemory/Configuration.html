Приоритеты озвучки

Первый подходящий вариант становится дорожкой по умолчанию. Ручной выбор для сезона важнее этого списка.

Пустой список оставляет обычный выбор Emby. «Любой дубляж» исключает дорожки с пометкой 18+.

18+ определяется по названию дорожки. Отсутствие пометки не гарантирует отсутствие мата.

Обучение происходит при ручной смене аудиодорожки во время просмотра.

При пустом названии сохраняется индекс дорожки; если порядок в следующей серии отличается, озвучка может оказаться другой.
