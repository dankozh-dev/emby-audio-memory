# Audio Memory для Emby

[English](README.md) · [Версии](https://github.com/dankozh-dev/emby-audio-memory/releases) · [Изменения](CHANGELOG.md)

Выберите аудиодорожку в одной серии — плагин применит этот выбор к остальным сериям того же сезона, отдельно для каждого пользователя Emby.
Это полезно, когда в файлах есть несколько озвучек на одном языке.

**Предварительная экспериментальная версия.** Работа на сервере проверена с **Emby Server 4.10.2.0**.
Смена дорожки в настоящем приложении Android с последующим автоматическим переходом к следующей серии **пока не проверена**.

## Как работает

1. Вы переключаете аудиодорожку во время просмотра.
2. Плагин получает событие Emby `AudioTrackChange` и сохраняет выбор для этого пользователя и сезона.
3. Он заранее записывает подходящий индекс аудиодорожки для остальных серий, которые сейчас не воспроизводятся.
4. Новые серии получают настройку после добавления в библиотеку или при выполнении задания раз в 15 минут.

Плагин меняет сохранённый выбор аудио; сами медиафайлы остаются прежними.
Он не отправляет команды плееру; при сохранении аудиодорожки сохраняет отметку просмотра, позицию, счётчик просмотров, оценки, избранное и выбор субтитров.
У серий, которые сейчас воспроизводятся в любой сессии сервера, плагин не меняет сохранённый выбор аудио.

### Сопоставление дорожек

| Сведения о дорожке | Выбор в следующей серии |
| --- | --- |
| У сохранённой дорожки есть название | Совпадение **названия и языка** без учёта регистра и повторяющихся пробелов. |
| У единственной подходящей дорожки изменился индекс | Используется её новый индекс. |
| У сохранённой дорожки нет названия | Используется тот же индекс Emby, если по нему находится аудиодорожка. |
| Совпадения по названию нет, а дорожка по сохранённому индексу безымянная | Используется этот индекс. |
| Совпадений несколько, указано другое непустое название или подходящей дорожки нет | Плагин не меняет выбор аудиодорожки. |

Серия воспроизводится как обычно. Если плагин не меняет выбор, дорожку определяет обычная логика Emby и клиента; ранее сохранённый выбор не сбрасывается к дорожке по умолчанию.

`Студия А`, `Студия А (дубляж)` и `Студия А 18+` считаются разными озвучками; плагин не угадывает синонимы названий.
**Выбор по индексу не определяет студию и не проверяет язык.** Если порядок безымянных дорожек меняется между сериями, может включиться другая озвучка.
Индекс Emby — поле `Index` в сведениях о потоке, а не порядковый номер в меню аудиодорожек.

## Установка

1. Скачайте `Emby.AudioMemory.dll` и `SHA256SUMS` со [страницы версий](https://github.com/dankozh-dev/emby-audio-memory/releases).
2. Сверьте SHA-256 файла DLL со значением в `SHA256SUMS`.
3. Остановите Emby Server и положите DLL в его каталог `plugins`. При обновлении сначала уберите прежнюю DLL из этого каталога.
4. Запустите сервер и откройте **Панель управления → Плагины → Audio Memory**.
5. Добавьте публичные идентификаторы нужных пользователей, включите плагин и сохраните настройки.
6. У каждого выбранного пользователя включите настройку воспроизведения **Запоминать выбор аудиодорожки** / **Remember audio track selection**.
7. Запустите серию и вручную переключите дорожку во время просмотра.

После установки плагин **выключен**, список разрешённых пользователей **пуст**.
Пустой список не включает всех пользователей — он запрещает изменения для всех.

Копировать нужно только DLL плагина, без библиотек Emby SDK и зависимостей сборки.
В Docker используйте постоянный том с каталогом плагинов, чтобы файл сохранился после пересоздания контейнера.
Расположение каталога и права доступа описаны в [инструкции Emby по ручной установке](https://emby.media/support/articles/Plugins.html).

### Как узнать идентификаторы пользователей

Выполните запрос `GET /Users` к своему серверу с токеном администратора.
Пример для оболочки, в которой уже задана переменная `EMBY_ADMIN_TOKEN`:

```sh
EMBY_API_URL='https://emby.example.org/emby'
curl --fail --silent --show-error \
  --header "X-Emby-Token: $EMBY_ADMIN_TOKEN" \
  "$EMBY_API_URL/Users"
```

Найдите нужную учётную запись по полю `Name` и скопируйте её `Id` в настройки плагина.
Нужен публичный GUID из API, а не имя, внутренний числовой идентификатор или идентификатор Emby Connect.
GUID принимается с дефисами и без них; нескольких пользователей укажите через запятую.
При необходимости измените адрес API с учётом своего обратного прокси; не помещайте токены в ссылки и сообщения об ошибках.

## Проверка

После переключения дорожки откройте настройки плагина: там должно появиться предпочтение для пользователя и сезона.
Запустите другую серию того же сезона и проверьте выбранный звук.
Отдельно проверьте обычный запуск и автоматический переход к следующей серии: приложение могло подготовить очередь до изменения настройки.

Если выбор не запоминается, проверьте список пользователей, настройку воспроизведения и передачу события `AudioTrackChange` приложением.
Для диагностики временно включите подробный журнал или прочитайте состояние через API ниже.
Автоматический выбор при запуске, обычные сообщения о прогрессе и остановка воспроизведения не меняют предпочтение плагина.

## API администратора

Все методы требуют авторизации администратора; пути указаны относительно адреса API Emby.
У всех POST-запросов по умолчанию `DryRun: true` — только проверка; для применения явно передайте `false`.

| Метод и путь | Назначение |
| --- | --- |
| `GET /AudioMemory/Status` | Предпочтения, исходные индексы для отката, последние события и ошибки состояния. |
| `POST /AudioMemory/Seed` | Задать предпочтение по существующей серии и индексу дорожки. |
| `POST /AudioMemory/Reconcile` | Применить активные предпочтения к подходящим сериям. |
| `POST /AudioMemory/Rollback` | Отключить предпочтение пользователя для сезона и восстановить исходные индексы там, где это возможно. |

В примерах используются вымышленные идентификаторы; замените все значения данными своего сервера:

```json
{"UserId":"<USER_GUID>","EpisodeId":1234,"AudioStreamIndex":3,"DryRun":true}
```

```json
{"DryRun":true}
```

```json
{"UserId":"<USER_GUID>","SeasonId":1200,"DryRun":true}
```

Это тела запросов `Seed`, `Reconcile` и `Rollback` соответственно.
`Seed` получает сезон и сведения о дорожке из указанной серии; произвольное название студии ему передать нельзя.
Для `Seed` и повторного применения нужно включить плагин и разрешить пользователя.
Откат доступен и при выключенном плагине.

## Отключение, откат и удаление

Отключение прекращает новые изменения, но оставляет уже сохранённый выбор аудио в Emby.
Для восстановления сезона выключите плагин, проверьте результат `Rollback` с `DryRun: true`, затем повторите с `false`.
Откат возвращает только те индексы, которые всё ещё соответствуют записи плагина, при неизменном источнике и составе дорожек.
Более поздний независимый выбор сохраняется; для воспроизводимых серий откат не выполняется — повторите его после остановки просмотра.
После нужного отката остановите Emby, удалите `Emby.AudioMemory.dll` и запустите сервер.

Состояние хранится в `<Emby DataPath>/audio-memory/state.json`.
Сохраняйте этот файл при обновлении и включите его в резервные копии: он нужен для отката.
Исходный индекс записывается до изменения Emby; при ошибке чтения или сохранения состояния дальнейшие записи прекращаются.

## Совместимость и ограничения

- Сборка использует **Emby SDK 4.9.1.90** и **.NET Standard 2.0**; проверка с настоящим сервером выполнена на **4.10.2.0**. Другие версии сервера не проверены.
- Реальная смена дорожки на Android и переход к следующей серии из готовой очереди пока не проверены; приложение может передать старый индекс поверх сохранённого сервером.
- Приложение должно отправлять `AudioTrackChange`. Выбор на карточке серии до запуска может не создавать это событие.
- Предпочтение общее для устройств одного пользователя, но отдельное для каждого сезона. Побеждает последнее полученное ручное изменение; между сезонами выбор не переносится.
- Для серий с несколькими источниками или версиями плагин не меняет выбор аудио; то же правило действует при изменении источника или состава дорожек после записи плагина.
- Для дорожки с названием нужен тег языка. При неоднозначном совпадении плагин не меняет выбор аудио; для безымянных дорожек действует описанный выше выбор по индексу.
- Публичный API Emby сохраняет пользовательские данные целиком. Повторное чтение, копирование и проверки активности снижают риск гонок, но не образуют общую транзакцию с обновлением прогресса просмотра.
- Это серверный плагин Emby. **Совместимость с Jellyfin не заявляется.**

## Сборка и проверки

Установите **.NET 8 SDK** и Bash, затем выполните из корня репозитория:

```sh
bash build.sh
```

Сценарий восстановит пакеты, соберёт плагин, запустит модульные проверки и проверки поведения, затем создаст `artifacts/Emby.AudioMemory.dll` и `SHA256SUMS`.
Закрытый источник пакетов и учётные данные сервера для сборки не требуются.
.NET 8 SDK нужен для сборки; среду выполнения на сервере предоставляет Emby.

Отдельный запуск проверок:

```sh
dotnet run --project tests/Unit/Unit.csproj -c Release
dotnet run --project tests/Behavior/Behavior.csproj -c Release
```

Проверки поведения используют подмены SDK для воспроизведения обычных сценариев и отказов; они не заменяют проверку на настоящем сервере и в приложении.
Требования к изменениям описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
